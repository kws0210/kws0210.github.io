# 카카오페이 돈키호테 쿠폰 근거

확인일: 2026-10-22 (한국시간)

## 현재 결론

제공된 최대 7% A+ REWARDS 쿠폰은 약관 6항에서 알리페이 제공 프로모션과의 중복을 명시적으로 허용한다.
그러나 현재 제공된 A+ 2,000엔 쿠폰의 전체 약관과 제외 조건을 공개 자료에서 확보하지 못했다.
따라서 이 두 쿠폰의 정확한 조합은 사용자가 보유 쿠폰 조건을 확인한 경우에만 합산한다.
중복 확인이 없어도 2,000엔 쿠폰 단독 할인은 비교에 포함한다.
최대 7%를 모든 결제에 7%로 계산하지 않는다.
확인한 구간 할인율을 설정에 한 번 저장해 자동 계산하며 미확인 구간은 합산하지 않는다.

## 돈키호테 17,000엔 검증

일본 페이머니 준비·2,000엔 쿠폰 보유·사용 0회일 때, 추가 매장 쿠폰 없이도 카카오페이 2,000엔 할인(11.76%)·예상 결제 15,000엔을 비교에 포함한다.
KB 10%만 적용하면 1,700엔이므로 해당 조건의 카카오페이가 더 유리하다.
각 결제수단의 다른 매장 쿠폰·즉시 할인까지 선택하면 총 할인액으로 다시 비교한다.
실제 공개 페이지의 별도 테스트 번호에서 카카오페이 추천을 확인했다.
사용자가 보고한 트래블카드 결과 자체는 같은 조건으로 재현하지 못했다.
별도로 횟수를 수정해도 이전 결과가 남는 표시 문제를 재현해 수정했다.
이를 사용자 사례의 확정 원인으로 단정하지 않는다.
