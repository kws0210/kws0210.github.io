# 카카오페이 돈키호테 쿠폰 근거

확인일: 2026-10-22 (한국시간)

## 현재 결론

제공된 최대 7% A+ REWARDS 쿠폰은 약관 6항에서 알리페이 제공 프로모션과의 중복을 명시적으로 허용한다.
그러나 현재 제공된 A+ 2,000엔 쿠폰의 전체 약관과 제외 조건을 공개 자료에서 확보하지 못했다.
따라서 이 두 쿠폰의 정확한 조합은 합산하지 않고 각각의 할인액을 비교한다.
중복 여부를 이용자에게 묻지 않으며 기존 `kakaoStackConfirmed` 값이 true여도 합산하지 않는다.
이는 중복 불가를 확정한 판단이 아니라 확인되지 않은 할인액을 추천에서 제외한 정책이다.
2,000엔 쿠폰 단독 할인은 계속 비교에 포함한다.
최대 7%를 모든 결제에 7%로 계산하지 않는다.
확인한 구간 할인율을 설정에 한 번 저장해 자동 계산하며 미확인 구간은 합산하지 않는다.

## 돈키호테 17,000엔 검증

일본 페이머니 준비·2,000엔 쿠폰 보유·사용 0회일 때, 추가 매장 쿠폰 없이도 카카오페이 2,000엔 할인(11.76%)·예상 결제 15,000엔을 비교에 포함한다.
KB 10%만 적용하면 1,700엔이므로 해당 조건의 카카오페이가 더 유리하다.
각 결제수단의 다른 매장 쿠폰·즉시 할인까지 선택하면 총 할인액으로 다시 비교한다.
실제 공개 페이지의 별도 테스트 번호에서 카카오페이 추천을 확인했다.
사용자가 보고한 트래블카드 결과 자체는 같은 조건으로 재현하지 못했다.
별도로 횟수를 수정해도 이전 결과가 남는 표시 문제를 재현해 수정했다.
이를 사용자 사례의 확정 원인으로 단정하지 않는다.

## 오사카 점포 대조 및 첫 화면 8곳 오류 정정

[공식 행사](https://m.unionpayintl.com/cardholderServ/serviceCenter/wap/merchant/121795293892?type=1)의 점포 목록은 페이지당 8개이며 스크롤할 때 다음 페이지를 가져온다.
초기 8개를 전체 대상이라고 안내한 이전 가이드는 잘못이었다.
[페이지가 실제 사용하는 공개 점포 API](https://m.unionpayintl.com/cardholderServ/serviceCenter/getStoreContents?offerCode=260907112832&languageId=kr&pageNumber=1&pageSize=1000)에서 115곳을 확보했고 8개씩 조회한 15페이지의 마지막 3곳과 16페이지의 빈 목록도 확인했다.
`hasMore`는 마지막 비어 있지 않은 페이지에서도 true이므로 빈 다음 페이지까지 확인했다.
[돈키호테 공식 오사카부 목록](https://www.donki.com/store/shop_list.php?pref=28)의 46개 점포와 전화번호로 대조하면 15곳이 행사 목록에 있다.
교바시점은 주소가 ‘오오사카’로 표기되어 ‘오사카’ 단순 검색에서 빠지므로 이름·전화번호도 함께 확인했다.

확인된 15곳은 도톤보리, 도톤보리 미도스지, 난바 센니치마에, 우메다 본점, 에키돈키 에키마르쉐 오사카, MEGA 신세카이, 아베노 텐노지 에키마에, 교바시, 텐마에키, 쥬소, 우에혼마치, 사쿠라노미야, 호엔자카, 이즈미사노, 린쿠다.
MEGA 벤텐초·MEGA 후카에바시·데라다초역점 등은 행사 목록에 없다.
그러므로 오사카 전체 점포를 대상으로 가정하지 않는다.
이용자는 돈키호테 선택 시 목록 이름을 보여주는 팝업에서 이번 방문 점포가 있는지 답한다.
`options.donkiStoreGroup`이 `osaka-listed`인 거래에서만 500엔·4,000엔 전용 행사를 비교한다.
아니요·모르겠어요·미입력·잘못된 값은 전용 행사만 제외하고 KB 공통 10%·보유 매장 쿠폰은 유지한다.
답변은 계산 뒤 초기화하며 이전 설정의 `unionDonkiEligible` 플래그는 추천에 사용하지 않는다.
대조 표와 출처는 [OSAKA_STORES.md](OSAKA_STORES.md)에 보존한다.
