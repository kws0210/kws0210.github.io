# 해외 결제·환전 비용 확인

확인일: 2026-10-22 (한국시간)

## 적용 상태

사용자는 카드 수수료와 환전 수수료도 확인할 수 있으면 계산에 포함하도록 요청했다.
사용자는 예시로 안내한 KB 노리 체크(UnionPay)·트래블로그 체크로 우선 가정해 구현하도록 답했다.
노리의 이용료는 아래 공식 안내의 불일치를 반영해 즉시 할인 후 결제액의 0.25~1.05% 예상 범위로 계산한다.
이 범위는 확정 요율이나 환전 비용 전체의 상한이 아니다.
트래블로그는 JPY 충전·해외 가맹점 이용 수수료 면제를 반영하고 잔액 원화 환급 비용은 매장 결제에 더하지 않는다.
카카오페이의 수수료 포함 실제 환율은 공개 조회 API를 확보하지 못해 비용을 null(미확인)로 둔다.
모든 후보의 100엔당 원화 비용(수수료 포함)이 있으면 할인 후 금액을 환산해 원화 총지출로 정렬하며 같은 수수료를 다시 더하지 않는다.
실제 환율이 일부만 있으면 원화 총지출로 재정렬하지 않는다.
카카오 후보가 없을 때는 같은 환율 가정에서 KB 상한 수수료까지 반영한 지출로 비교하며 이 가정을 표시한다.
카카오 후보의 환율이 미확인이면 할인액 기준 잠정 추천과 확인한 카드 수수료 범위를 함께 표시한다.
입력 환율은 화면 메모리에서 30분간 유효하고 브라우저에는 저장하지 않으며 로그아웃 시 초기화한다.
계산 요청의 환율은 서버 operations 결과에 함께 남지만 다음 로그인 설정으로 복원하지 않는다.
결과·비교 표·하단 기준과 별도 `/japan-payment/basis/#payment-costs`에 계산 범위를 표시한다.
준비 가이드는 8개 접힌 준비 목록으로 줄이고 긴 비용·중복·대상 점포 근거는 basis로 분리했다.
미확인 비용을 0원으로 간주하거나 할인액 기준 추천을 원화 총지출 최저라고 주장하지 않는다.

## 계산 원칙과 확인 한계

1. 사용자가 동의한 예시 카드 가정을 표시하고 카드가 다르면 기준을 갱신한다.
2. 매장 쿠폰과 즉시 결제 할인 후 실제 청구 대상 금액·수수료 부과 기준을 확인한다.
3. 카카오페이는 수수료 포함 적용 환율, KB는 브랜드 환산·은행 송금환율·별도 이용료, 트래블은 실제 엔화 충전 환율과 상품별 이용료로 원화 예상 지출을 계산한다.
4. 이미 포함된 수수료를 이중 합산하지 않는다.
5. 모든 후보의 수수료 포함 입력 환율이 있을 때 원화 총지출을 기준으로 추천한다. 미확인 후보 비용을 0으로 채워 원화 순위를 만들지 않는다.
6. Frankfurter USD/JPY는 50달러 조건용 참고 환율이다. 실제 결제·충전 환율이나 환전 스프레드로 대체하지 않는다.
