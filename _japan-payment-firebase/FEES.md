# 해외 결제·환전 비용 확인

확인일: 2026-10-22 (한국시간)

## 적용 상태

사용자는 카드 수수료와 환전 수수료도 확인할 수 있으면 계산에 포함하도록 요청했다.
실제 KB 유니온페이·트래블카드 상품명은 확인을 요청했으며 아직 답변을 받지 못했다.
현재 추천은 할인액 기준이고 수수료·환전 차이는 미반영이다.
결과·비교 표·하단 기준·준비 가이드에 이 범위를 표시한다.
미확인 비용을 0원으로 간주하거나 할인액 기준 추천을 원화 총지출 최저라고 주장하지 않는다.

## 후속 계산 원칙

1. 실제 카드 상품을 확인하고 현재 상품 약관·면제·환산 경로를 확정한다.
2. 매장 쿠폰과 즉시 결제 할인 후 실제 청구 대상 금액·수수료 부과 기준을 확인한다.
3. 카카오페이는 수수료 포함 적용 환율, KB는 브랜드 환산·은행 송금환율·별도 이용료, 트래블은 실제 엔화 충전 환율과 상품별 이용료로 원화 예상 지출을 계산한다.
4. 이미 포함된 수수료를 이중 합산하지 않는다.
5. 모든 후보의 비용이 비교 가능할 때 총지출을 기준으로 추천한다. 미확인 후보 비용을 0으로 채워 순위를 만들지 않는다.
6. Frankfurter USD/JPY는 50달러 조건용 참고 환율이다. 실제 결제·충전 환율이나 환전 스프레드로 대체하지 않는다.
