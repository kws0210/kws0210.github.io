# 해외 결제·환전 비용 확인

확인일: 2026-10-22 (한국시간)

## 적용 상태

사용자는 카드 수수료와 환전 수수료도 확인할 수 있으면 계산에 포함하도록 요청했다.
KB 노리 체크(UnionPay)는 사용자가 승인한 예시 상품으로 가정한다.
사용자는 2026-10-22 트래블카드를 트래블월렛으로 정정했으며 엔화 잔액을 충전해 결제하는 트래블페이 카드 기준으로 반영한다.
노리의 이용료는 아래 공식 안내의 불일치를 반영해 즉시 할인 후 결제액의 0.25~1.05% 예상 범위로 계산한다.
이 범위는 확정 요율이나 환전 비용 전체의 상한이 아니다.
트래블월렛은 공식 안내의 엔화 환전·해외 결제 수수료 0%를 반영한다.
엔화 잔액 결제의 추가 수수료 계산값은 0이며 실제 원화 지출은 충전 당시 앱 환율에 따라 달라진다.
잔액 환불은 별도 거래이며 환불 시 고시 환율과 충전 환율의 차이를 이번 매장 결제 수수료로 더하지 않는다.
카카오페이의 수수료 포함 실제 환율은 공개 조회 API를 확보하지 못해 비용을 null(미확인)로 둔다.
이용자에게 수수료나 실결제 환율을 입력받지 않고 확인한 이용료를 자동 계산한다.
KB는 할인 후 결제액의 예상 이용료 상한 1.05%를 예상 할인액에서 차감해 트래블월렛·카카오페이와 비교한다.
카카오 후보가 있으면 앱 환율에 포함된 미확인 비용을 더하지 못한 잠정 순위이며, 카카오 비용을 0원으로 확정하지 않는다.
카카오 후보가 없으면 같은 환율 가정에서 KB 예상 이용료를 차감한 혜택으로 비교한다.
실제 청구·충전 환율 차이는 미반영이므로 원화 총지출 최저를 확정하지 않는다.
자동 조회 환율은 서버 operations 결과에 함께 남지만 다음 로그인 설정으로 복원하지 않는다.
결과·비교 표·하단 기준과 별도 `/japan-payment/basis/#payment-costs`에 계산 범위를 표시한다.
준비 가이드는 8개 접힌 준비 목록으로 줄이고 긴 비용·중복·대상 점포 근거는 basis로 분리했다.
미확인 비용을 0원으로 간주하거나 할인액 기준 추천을 원화 총지출 최저라고 주장하지 않는다.

## 계산 원칙과 확인 한계

1. KB 노리의 예시 상품 가정과 사용자가 정정한 트래블월렛 엔화 잔액 결제 기준을 구분한다.
2. 매장 쿠폰과 즉시 결제 할인 후 실제 청구 대상 금액·수수료 부과 기준을 확인한다.
3. 확인한 이용료를 자동 반영하고, 이용자에게 실결제 환율 조사를 맡기지 않는다.
4. 예상 할인액에서 KB 예상 이용료 상한을 한 번 차감한다. 미확인 카카오 비용은 null로 유지하며 원화 총지출을 만들어내지 않는다.
5. 결제수단별 실제 환율 차이가 미반영임을 안내하고 카카오 후보가 있으면 잠정 추천으로 표시한다.
6. Frankfurter USD/JPY는 50달러 조건용 참고 환율이며 조회 실패 시 ExchangeRate-API로 재시도한다. 제공처·기준일을 표시하고 실제 결제·충전 환율이나 환전 스프레드로 대체하지 않는다.

## 폐기한 방식

100엔당 수수료 포함 원화 비용을 직접 입력받아 원화 총지출을 비교하던 기능은 2026-10-22 사용자 피드백으로 제거했다.
확인된 이용료를 자동 계산하는 방식으로 대체했으며 과거 서버 거래 기록은 삭제하지 않는다.
