카카오페이

  1. 일본 페이머니 준비국가를 일본으로 바꾸고 잔액 준비

    카카오페이 → 결제 → 상단 태극기 버튼 → 일본을 선택한다.
    마지막 화면의 일본 · Alipay+ · 페이머니를 확인하고 잔액을 준비한다.

    카카오페이 결제 열기 ↗
    카카오페이 여는 화면
    1. 결제 메뉴 누르기
    2. 태극기 버튼 → 일본 선택
    3. 일본 페이머니 화면 확인
  2. 결제 할인 쿠폰 받기돈키호테 2,000엔 · 간사이공항 1,200엔

    결제 → 해외 · 일본 → 현지 쿠폰 받기에서 이용할 매장의 지금 받기를 누른다.

    • 돈키호테: 15,000엔 이상 → 2,000엔 할인
    • 간사이공항: 10,000엔 이상 → 1,200엔 할인
    카카오페이 열고 쿠폰 찾기 ↗

    돈키호테 쿠폰 화면

  3. 돈키호테 최대 7% 쿠폰 받기돈키호테 이용 시 · 결제 전에 점원에게 제시

    같은 현지 쿠폰 메뉴에서 최대 7% 할인 Don Quijote를 받는다.
    살짝 밀어서 사용 → 지금 사용하기는 미리 누르지 않고 계산대에서 직원과 함께 진행한다. 캡처 화면은 사용할 수 없다.

KB 유니온페이

  1. KB 유니온페이 실물 카드 준비보유 중이면 발급 생략

    노리 체크카드 · UnionPay(은련)를 기준으로 안내한다.
    신청 화면에서 국제브랜드를 UnionPay로 선택한다. 이미 대상 KB 개인 신용·체크카드가 있으면 새로 발급받지 않아도 된다.

    노리 체크카드 발급·신청 ↗
  2. 일본 10% 행사 등록카드 등록 후 ‘선택확인’까지
    일본 10% 행사 등록하기 ↗
    1. 등록하기 → SMS 인증 코드로 로그인을 누른다.
    2. 국가번호 +82를 선택하고 문자 인증을 진행한다.
    3. 카드번호 등록 → 사용할 카드 선택 → 선택확인을 누른다.
    4. 이벤트 수령 기록에서 등록 완료를 확인하고 약 2분 뒤 결제한다.

    50달러 이상 현지 실물 카드 결제 · 10% 할인 · 건당 최대 20달러 · 최대 3회.
    2026. 9. 14. ~ 12. 31., 예산 소진 시 종료.

    공식 행사 조건 보기 ↗
  3. 돈키호테 전용 혜택 준비매장 쿠폰 받기 · 4,000엔 행사는 별도 등록
    유니온페이 전용 매장 쿠폰 받기 ↗

    쿠폰 바코드가 표시되는지 확인하고 결제 전에 점원에게 보여준다. 표시되지 않으면 아래 KB 안내의 쿠폰다운으로 다시 들어간다.

    돈키호테 4,000엔 행사 별도 등록 ↗

    위 10% 행사와 별도로 문자 인증 → 카드 등록 → 사용할 카드 선택확인까지 마친다.

    쿠폰 후 40,000엔 이상이면 4,000엔, 10,000엔 이상 500엔 행사는 등록 없이 비교한다. 각 최대 3회·하루 1회다. 계산기 팝업에서 지점을 선택하면 대상 여부를 자동 반영한다.

    KB 전체 행사·쿠폰다운 ↗ 전용 행사 공식 조건 ↗

마지막 준비

  1. 트래블월렛 엔화 충전부족한 잔액을 미리 준비

    트래블월렛 앱에서 일본 엔화(JPY) 잔액을 충전하고 카드를 활성화한다.
    엔화 환전·해외 결제 수수료는 0%다. 원화 지출 비교에는 실제 충전 환율을 사용한다.

    트래블월렛 공식 안내 ↗
  2. 받은 쿠폰·등록 상태 저장계산기 상단 설정에서 한 번 저장

    계산기에 로그인한 뒤 설정에서 실제 보유 카드·쿠폰과 완료한 행사 등록만 선택한다.
    저장하고 계산하기를 누르면 준비가 끝난다.
